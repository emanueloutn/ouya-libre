# OuyaLibre 0.6 — prototipo para OUYA

Aplicación nativa para Android 4.1/API 16. Incluye conectores públicos, resolución MP4/HLS e iframes compatibles, comprobación de candidatos, favoritos, historial, reanudación y mando OUYA.

Las búsquedas pendientes se detienen al reproducir y el reproductor muestra estadísticas de transporte durante pausas prolongadas. El conector de OK.ru valida el JSON público del reproductor sin depender de la descarga completa de la página.

Limitación destacada: la búsqueda web general puede recibir HTTP 429 o comprobaciones de acceso. Consulta el README; no se garantiza encontrar o reproducir cualquier película.

Probada en hardware real. Código bajo MIT; dependencias con sus licencias respectivas.
